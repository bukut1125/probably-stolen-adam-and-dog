# Project guidance

- Preserve the user's original game installation, existing characters, and saves. Never distribute game binaries or user save files.
- Keep Adam's story, preview and state per the specification in `src/AdamStory/StoryDesign.md`; preserve the dog as a separate customer.
- Keep role portraits unique, restore them after dictionary recreation, and never substitute a random vanilla portrait for a mod character.
- Run targeted story, transaction, and portrait tests after changes; distinguish synthetic checks, actual game loading, and in-game acceptance.
- Verify the target game build and mod loader capabilities before installation or release. Keep previous installed mod versions recoverable.
