# 下水道：等離子外洩

這是《深空當鋪：可能是偷的》的獨立模組，不取代原版水龍頭或其他模組。下水道管線有低機率發生等離子外洩，橫向玻璃管內會出現青紫色脈動特效。

- 未發生外洩時，每個遊戲日有 5% 的機率開始外洩，持續 2 至 4 個遊戲日；同一個存檔的同一天不會因重讀而重新抽籤。
- 污染只針對下水道接水管新接出的水，升級為鏽水後也可能發生；既有容器中的水不會被整瓶替換。濾器依遊戲原有規則處理新增的有毒成分。
- 外洩期間接出的水含原版的有毒液體成分，容器顯示青色並標示危險；混合、倒入其他容器後，毒性仍由遊戲原生液體系統處理。事件結束後，之前接出的污水不會自動變乾淨。
- 模組提供「特效預覽」選項，預設關閉；預覽只顯示特效，不會自行改變水質。

## 安裝

將 `personal.plasma-sewer` 資料夾放進遊戲的 `Mods` 目錄，在遊戲主選單啟用「下水道：等離子外洩」並依遊戲要求重新啟動。先使用獨立測試存檔檢查特效與接水效果。

## 驗證範圍

事件時間、來源隔離、容量、濾器、標記轉移與停用模組後原版毒性保留，已由模擬測試檢查。已檢查本機遊戲版本的接水與液體程式介面，並通過原版模組掃描；實際遊戲載入、動態特效位置、接水與存讀檔仍須遊戲內驗證。

## 美術

特效使用內建 imagegen 生成透明背景的青紫色像素風污水、氣泡與電弧。模組以動畫脈動呈現，素材位於 `Textures/Items/plasma_pipe_fx.png`。
