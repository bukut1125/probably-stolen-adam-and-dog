# Probably Stolen：亞當與狗狗

這是一組為《深空當鋪：可能是偷的》（Probably Stolen）製作的 Windows 本機模組，包含獨立的狗狗顧客，以及外星訪客亞當的分支故事。

## 目前狀態

目前包含狗狗 **0.1.1** 與亞當 **1.0.7**。此前的亞當 0.1.1 與狗狗 0.1.1 曾在 Steam build `26337366` 的遊戲主選單載入，玩家也已查看測試角色狀態。亞當 1.0.7 修正產礦裝置的狀態同步、操作範圍、說明與尺寸，在存檔物品載入至實際容器後檢查舊裝置的擴格，並使用重新繪製的橫向 4×3 裝置圖片，嘗試在安全條件下修正舊裝置保留的旋轉狀態；遊戲內已確認簡介顯示、橫向佔格與拖動，並由玩家確認新版圖片已橫向對齊；蓄滿後實際產礦及存讀檔持久性仍待遊戲內驗收。原生結局、完整交易及存讀檔也尚未完成遊戲內驗收；程式模擬不等同實際遊戲驗證。

## 內容

- **狗狗顧客**：新增客人，使用獨立立繪，想買食物，台詞是不同語氣的「旺」。每次顧客佇列生成時有約 30% 機率來訪，初始購物預算為 100–300。
- **亞當：墜落與歸途**：從第 23 個遊戲日起可展開正式劇情，包含資源交付、不同選擇、後續事件和結局。
- **角色狀態測試**：正式版預設關閉。若在模組設定中手動啟用，狗狗、外星人正常和三個飢餓狀態、拾荒裝，以及外星之神會在同一天排入佇列；測試對話不扣真實物品，也不推進正式劇情。
- **快速同行測試**：手動啟用測試模式後，全部狀態展示完成的第三個遊戲日，亞當會額外來訪，提供不影響正式故事的同行選擇和畫面預覽。完成測試選擇並跨日保存後，測試模式自動關閉。
- 正式初次援助可交一份食物**或**一份水；後續有電子元件、電池、100 kcal 食物與不同結局的選擇。
- 留下分支的新裝置占 **4×3 格**，每三個遊戲日蓄能，產出十個原版金屬礦石，使用原版渦輪增壓器音效。舊裝置載入時只會在原位置具備足夠空間、且方向符合遷移條件時擴大；否則保留原尺寸，調整空間及方向後重新載入。
- 正式的離開與壞結局使用遊戲原生的結束本局與結算流程，並顯示結局美術；觸發前請確認是自己的選擇。遊戲保留、載入歷史存檔的實際行為尚待驗證。

## 安裝

1. 關閉遊戲，備份自己的存檔。
2. 把 `dist/Mods` 內兩個資料夾放到遊戲安裝目錄的 `Mods` 資料夾。請勿覆蓋你自行修改過的同名模組；先保留原本的版本。
3. 啟動遊戲，在主選單的模組介面啟用「狗狗顧客」與「亞當：墜落與歸途」，然後重新啟動遊戲。若遊戲要求審閱，請先閱讀它顯示的資訊。
4. 正式故事最早於遊戲第 23 天登場。如要驗證而不影響正式劇情，可在模組設定手動啟用測試模式並使用獨立測試存檔。展示訪客需要依序呼叫；測試對話不消耗真正的物品，也不直接發放正式獎勵。

亞當模組的同日展示需要狗狗模組啟用。各模組使用自己的識別碼，並未刻意取代原版角色。關閉模組後，遊戲本身的每局模組資料會保留；自訂道具停用、重新啟用及跨版本行為仍需實測確認。

## 原始碼與測試

- `src/AdamStory`：故事、顧客、畫像與道具程式；`tests` 是純邏輯測試，`integration` 使用遊戲 API 替身，並非原版遊戲的端到端測試。
- `src/DogCustomer`：狗狗角色與畫像重新綁定修正。
- `dist/Mods`：可放入遊戲的模組檔案。

編譯需要 .NET SDK、自己的合法遊戲安裝及遊戲的 `Probably Stolen_Data/Managed` 程式庫；本儲存庫不包含遊戲程式庫或存檔。若遊戲安裝路徑不同，可用 MSBuild 屬性 `GameManaged` 指向自己的 Managed 目錄。美術為本專案生成素材，沒有包含使用者的原始狗狗照片。
